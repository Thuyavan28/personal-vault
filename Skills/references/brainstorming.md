# Brainstorming & Ideation

- Start divergent, converge later: generate many options before judging any of them.
- Techniques: "How might we...", SCAMPER (Substitute/Combine/Adapt/Modify/Put to other use/Eliminate/Reverse), reverse brainstorming (how would we make this fail?), 6-3-5 method, first-principles decomposition.
- Ground ideas against constraints only after divergence: budget, timeline, team skill, existing architecture, user needs.
- Always surface at least one "boring/safe" option and one "ambitious" option so the person can see the trade-off space, not just one path.
- Capture rejected ideas with a one-line reason — they're often revisited later and the reasoning saves re-litigating.
